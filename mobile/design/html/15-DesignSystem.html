Design system

Le mode sombre reprend les tokens de PFA web (surface-base, surface-elev, ink, accent-strong, elec, neg, exc, warn, GlowCard, CTA vert → bleu). Le mode clair en est dérivé : mêmes teintes, luminosités inversées, contrastes ≥ 4,5:1. Montants en Geist Mono à chasse fixe.
Unités : pt (iOS) = dp (Android)Cible tactile min. 44 pt / 48 dpFichier de tokens : pfa-mobile-tokens.ts
